Digital Hardware · Computer Architecture · SystemVerilog

Direct-Mapped Cache RTL Design

I designed a direct-mapped cache in SystemVerilog with a combinational tag-comparison and hit-detection path for single-cycle cache hits. Cache misses are handled by a finite-state machine that coordinates memory requests, waits for the external memory system, refills the selected cache line, updates metadata, and returns the requested data to the processor.

The design uses a wait-based memory-side handshake, requiring the cache controller to remain correct even when memory response latency varies. I verified the design with directed SystemVerilog testbenches covering hits, misses, refills, replacement behavior, processor-facing behavior, and memory-facing behavior, debugging failures by tracing signals through simulation waveforms.

Technical Areas

Direct-Mapped Organization Tag / Valid / Data Storage Address Decomposition Combinational Hit Detection FSM Control Multi-Cycle Miss Handling Memory Handshake Protocol Refill & Replacement Waveform Debugging

Key Challenges

  • Preserving a fast combinational path for hits while managing a multi-cycle miss path
  • Correctly coordinating state transitions with an external memory wait signal
  • Ensuring the processor receives valid data at the correct cycle
  • Separating metadata updates from request and response timing
  • Testing both normal cases and edge conditions
Digital Communications · Signal Processing · Python

OFDM Audio Communication System

I built an end-to-end OFDM communication system in Python that transmitted digital data through speakers and microphones over a real acoustic channel. The transmitter maps data into Gray-coded QAM symbols, assigns bits adaptively across OFDM subcarriers based on channel quality, generates time-domain frames, and plays the signal through audio hardware.

The receiver detects incoming frames via cross-correlation, corrects for clock-rate mismatch between transmitter and receiver, estimates the acoustic channel, equalizes each subcarrier, demodulates the QAM symbols, and reconstructs the transmitted data.

~70 kbps sustained throughput over a real speaker-to-microphone acoustic channel

Technical Areas

OFDM QAM Modulation / Demodulation Gray-Coded Constellations Adaptive Bit Loading Frame Synchronization Cross-Correlation Clock-Skew Correction Channel Estimation Equalization

Key Challenges

  • Real audio channels introduce echoes, frequency-dependent attenuation, noise, and hardware imperfections
  • Transmitter and receiver clocks don't run at exactly the same rate
  • Reliable synchronization is required before symbol recovery can begin
  • Different subcarriers experience different signal quality
  • The receiver must estimate and compensate for channel distortion in real time
Machine Learning · Computer Vision · Python

Multi-Label Digit Classification

I developed a machine-learning system that identifies pairs of overlaid handwritten digits — a harder problem than conventional single-label classification, since the model has to predict both digit classes visible in each image.

I trained and compared convolutional neural networks, support vector machines, and simpler baseline approaches, using preprocessing, data augmentation, cross-validation, and error analysis to reduce overfitting and improve generalization from a limited training set.

~97% overall test accuracy from the best-performing approach

Technical Areas

Multi-Label Classification Convolutional Neural Networks Support Vector Machines Data Augmentation Cross-Validation Error Analysis PyTorch scikit-learn NumPy / pandas

Key Challenges

  • Two digits may overlap heavily, with one partially obscuring the other
  • Digit order and label representation had to be handled consistently
  • Limited training data increased overfitting risk
  • Some digit combinations were more visually ambiguous than others

Study Partner Matching App

I helped build a full-stack Android application that matches students with compatible study partners. The app collects schedule availability, course overlap, and study preferences, then queries a relational database to return personalized matches.

I focused on the backend: data structures and the API workflow, including storing user profiles and schedules, processing partner-search queries, and returning matching results to the Android front end.

Technical Areas

Android Development REST API Design Relational Databases SQL Schedule Representation Search & Matching Logic

Key Challenges

  • Representing schedules in a form that can be searched efficiently
  • Combining hard constraints, like availability, with softer preferences
  • Structuring relational data across users, courses, and schedules
  • Designing API endpoints that return useful information to the front end
