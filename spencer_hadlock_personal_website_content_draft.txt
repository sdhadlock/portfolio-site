PROJECT 1: DIRECT-MAPPED CACHE RTL DESIGN
Category:
Digital Hardware / Computer Architecture / SystemVerilog

Suggested project tagline:
A SystemVerilog cache design combining single-cycle hit detection with multi-cycle miss handling.

Overview:

I designed a direct-mapped cache in SystemVerilog with a combinational tag-comparison and hit-detection path for single-cycle cache hits. Cache misses are handled by a finite-state machine that coordinates memory requests, waits for the external memory system, refills the selected cache line, updates metadata, and returns the requested data to the processor.

The design uses a wait-based memory-side handshake, requiring the cache controller to remain correct even when memory response latency varies. I created directed testbenches to validate hits, misses, refills, replacement behavior, processor-facing behavior, and memory-facing behavior.

Technical areas:
- Direct-mapped cache organization
- Tag, valid, and data storage
- Address decomposition
- Combinational hit detection
- Finite-state machine control
- Multi-cycle miss handling
- Memory handshake protocols
- Cache refill and replacement
- Processor and memory interfaces
- Directed SystemVerilog testing
- Waveform-based debugging

Challenges:
- Preserving a fast combinational path for hits while managing a multi-cycle miss path
- Correctly coordinating state transitions with an external wait signal
- Ensuring the processor receives valid data at the correct time
- Separating metadata updates from request and response timing
- Testing both normal cases and edge conditions

PROJECT 2: OFDM AUDIO COMMUNICATION SYSTEM
Category:
Digital Communications / Signal Processing / Python

Suggested project tagline:
An end-to-end OFDM modem transmitting data through an acoustic channel at approximately 70 kbps.

Overview:

I built an end-to-end orthogonal frequency-division multiplexing communication system in Python that transmitted digital data through speakers and microphones. The system achieved approximately 70 kbps of reliable data transmission over an acoustic channel.

The transmitter mapped data into Gray-coded QAM symbols, assigned bits adaptively across OFDM subcarriers, generated time-domain frames, and played the signal through audio hardware. The receiver detected frames, corrected clock mismatch, estimated the acoustic channel, equalized subcarriers, demodulated the QAM symbols, and reconstructed the transmitted data.

Technical areas:
- OFDM
- QAM modulation and demodulation
- Gray-coded constellations
- Subcarrier mapping
- Adaptive per-tone bit allocation
- Frame synchronization
- Cross-correlation
- Clock-skew correction
- Channel estimation
- Equalization
- Iterative receiver improvement
- Real-time audio input and output
- Python signal-processing pipelines

Result:
Approximately 70 kbps over an acoustic channel.

Challenges:
- Real audio channels introduce echoes, frequency-dependent attenuation, noise, and hardware imperfections
- Transmitter and receiver clocks do not run at exactly the same rate
- Reliable synchronization is necessary before symbol recovery can begin
- Different subcarriers have different signal quality
- The receiver must estimate and compensate for channel distortion

A dual-output image-classification system for identifying two overlaid handwritten digits.
